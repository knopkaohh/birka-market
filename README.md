Новая конверсионная версия сайта производителя бирок, упаковки, фурнитуры, мерча и полиграфии. Сохранены фирменные цвета, реальные фотографии и ассортимент действующего сайта birka-market.ru.

## Запуск

```bash
npm install
npm run dev -- --port 43127
```

Откройте `http://localhost:43127`.

## Что внутри

- Главная с каталогом направлений и формой расчёта. Единый CTA «Рассчитать заказ» ведёт на `/raschet` или к блоку `#calc` на посадочной
- На мобильном экране вместо плавающей кнопки нижняя панель «Позвонить / Рассчитать заказ», чтобы не перекрывать форму
- 7 категорий и 32 посадочные страницы материалов: те же блоки, что у жаккарда, уникальные тексты, фото и полная форма расчёта
- Боковое меню работает и в превью, и на временном домене: клики обрабатываются даже если клиентский JS Next.js не поднялся
- Верхнее меню: продукция, о компании, доставка, оплата, контакты, FAQ. Телефон в шапке до планшета, WhatsApp в шапке и нижней панели. Юридическая строка в подвале — ИП Федотов Антон Вадимович
- Бесшовная бегущая строка и виджет Яндекс Карт с рейтингом
- О компании, доставка, оплата, контакты, FAQ и политика
- Рабочая заявка: `/api/lead` сохраняет лид и вложение, затем открывается страница «Спасибо»

## Проверки

```bash
npm run lint
npm run build
```

Перед промышленным запуском подключите CRM, Яндекс Метрику и постоянное файловое хранилище.
