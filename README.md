# Бирка Маркет

Новая конверсионная главная страница производителя бирок, упаковки и фурнитуры для одежды. Дизайн сохраняет фирменные тёмно-серый и жёлтый цвета, использует реальные фотографии работ и ведёт посетителя к быстрому расчёту заказа.

## Запуск

```bash
npm install
npm run dev -- --port 43127
```

Откройте `http://localhost:43127`.

## Проверки

```bash
npm run lint
npm run build
```

Форма отправляется в демонстрационный обработчик `/api/lead`. Перед промышленным запуском его необходимо подключить к CRM, файловому хранилищу, Яндекс Метрике и защите от спама. Контакты, сроки и условия также следует подтвердить у Birka Market.
