Новая конверсионная версия сайта производителя бирок, упаковки, фурнитуры, мерча и полиграфии. Сохранены фирменные цвета, реальные фотографии и ассортимент действующего сайта birka-market.ru.

## Запуск

```bash
npm install
npm run dev -- --port 43127
```

Откройте `http://localhost:43127`.

## Что внутри

- Главная с каталогом направлений и формой расчёта
- 7 категорий и 32 посадочные страницы материалов: те же блоки, что у жаккарда, уникальные тексты, фото, полная форма расчёта и закреплённый в левом нижнем углу «Быстрый расчет» (имя и телефон)
- Верхнее меню как на birka-market.ru: продукция, о компании, доставка, оплата, контакты, новости, FAQ
- Бесшовная бегущая строка и виджет Яндекс Карт с рейтингом
- О компании, доставка, оплата, контакты, новости, FAQ и политика
- Рабочая заявка: `/api/lead` сохраняет лид и вложение, затем открывается страница «Спасибо»

## Проверки

```bash
npm run lint
npm run build
```

Перед промышленным запуском подключите CRM, Яндекс Метрику и постоянное файловое хранилище.
