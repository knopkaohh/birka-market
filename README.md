Новая конверсионная версия сайта производителя бирок, упаковки, фурнитуры, мерча и полиграфии. Сохранены фирменные цвета, реальные фотографии и ассортимент действующего сайта birka-market.ru.

## Запуск

```bash
npm install
cp .env.example .env.local
npm run dev -- --port 43127
```

Откройте `http://localhost:43127`.

Для рекламы в Яндекс Директе укажите в `.env.local` номер счётчика Метрики:

```
NEXT_PUBLIC_YANDEX_METRIKA_ID=12345678
```

После заявки открывается окно `#lead-thanks` и отправляется цель `LEAD`. В Метрике создайте цель типа «JavaScript-событие» с идентификатором `LEAD` или цель по элементу `#lead-thanks`. Эту же цель привяжите к кампаниям Директа.

## Что внутри

- Главная с каталогом направлений и формой расчёта. Единый CTA «Рассчитать заказ» ведёт на `/raschet` или к блоку `#calc` на посадочной
- После заявки — всплывающее окно: менеджер свяжется в течение 10 минут
- На мобильном экране вместо плавающей кнопки нижняя панель «Позвонить / Рассчитать заказ», чтобы не перекрывать форму
- 7 категорий и 32 посадочных: материалы, упаковка, фурнитура, мерч и полиграфия. Посадочные готовы под объявления Директа: телефон, цены, форма, юридические данные
- Боковое меню работает и в превью, и на временном домене
- Верхнее меню: продукция, как выбрать, о компании, новости, доставка, оплата, контакты, FAQ
- Страница `/kak-vybrat` помогает новичку выбрать материал, подгибку, цвета и тираж; `/guide` и `/podbor` ведут туда же
- Лента новостей `/novosti` и 22 статьи с датами и текстом со старого сайта; старые адреса `/news` и `/blog/...` ведут на новые страницы
- Поиск по 32 позициям в каталоге и боковом меню
- Заявка: форма отправляет `POST /api/lead`, бэкенд проверяет те же поля и сохраняет лид в `data/leads.json`

## Проверки

```bash
npm run lint
npm run build
```

Перед промышленным запуском подключите CRM, номер счётчика Метрики и постоянное файловое хранилище.
